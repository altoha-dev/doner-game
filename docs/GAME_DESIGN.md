# DONER GAME — Winter Party Edition

Stage 6.1.5 / **v0.6.1.5 Player Interactions + Ayazhan**. Зимний party platformer на одной карте для 2–4 друзей. Старая Solo Campaign и разные миры героев остаются историей прототипа.

## Игровая петля

HOME → создать комнату / войти по коду или приглашению → LOBBY → выбрать героя → READY → host начинает BUILD → каждый ставит блок или пропускает → общий RACE → одинаковые RESULTS → host запускает следующий BUILD. Старые блоки сохраняются; новая комната начинает с базовой карты.

Online: до 5 раундов, BUILD 60 секунд, RACE 90 секунд, TTL 2 часа. Если все участники закончили свои действия, фаза меняется сразу. После результатов пятого раунда host завершает матч. Победителя по накопленным очкам пока нет.

Локальная **ТРЕНИРОВКА** сохранена: один игрок, BUILD → RACE → RESULTS, до 12 раундов/блоков. Работает без API, бота и аккаунта, в dev и production. Время — локальное время активной симуляции без пауз; выход/reload завершает local session.

## Общая арена и управление

SNOWY CHAOS: 1152×320 logical pixels, grid 16, четыре стартовых места, финиш и уступы. Сплошной пол позволяет играть без death/respawn. У героев общая geometry и body 10×21. Поверхность выглядит ледяной, physics материалов одинакова. Декорации не имеют скрытых коллизий.

Сохранены speed/acceleration/drag/gravity/jump, coyote time 80ms, buffer 100ms, camera follow и collisions. A/D или ←/→; W/↑/Space — jump; P/Escape — pause. На телефоне left/right/jump с multi-touch и очисткой удержаний при pointer cancel/blur.

Online pause останавливает собственное управление; серверная физика, таймер и друзья продолжают матч. Remote players непрозрачные, с Telegram names и interpolation. Игроки сопротивляются встречному движению, толкаются, запрыгивают на голову, стоят на ней и прыгают с неё. Стены и установленные блоки ограничивают толчок; контакт не позволяет пройти сквозь geometry.

Все взаимодействия считает сервер фиксированными шагами 60 Hz. Клиент предсказывает отклик тем же solver и сверяется с snapshots 15 Hz. Толчок стоящего игрока ограничен 36px/s; head jump добавляет 12px/s к обычному прыжку 224px/s. Это одинаковые базовые действия всех героев. Короткие pixel impacts показывают контакт и отключаются в reduced motion.

## BUILD

Каждый получает **один бесплатный BASIC PLATFORM BLOCK 32×16 за раунд**. Выбрать → preview → коснуться карты или сдвинуть стрелками → подтвердить. Отмена убирает preview; подтверждённый блок нельзя передвинуть. Online есть SKIP, после своего хода игрок ждёт остальных. На deadline незавершённые ходы пропускаются.

Масштаб ×2 сохраняет размер блоков; отдельный ползунок двигает обзор. Стрелки смещают на 16px. Online участники видят перемещение полупрозрачных previews друзей: цвет seat, Telegram display name и ✓/×; красная рамка означает запрет. Local preview зелёный/красный. Сервер проверяет online placement validity, включая занятое другим блоком место; training использует ту же validation.

Live previews обновляются до 12 Hz, не являются платформами и не записываются в БД. Confirm создаёт настоящий блок; cancel, SKIP, disconnect, конец BUILD или expiry убирают ghost. Reconnect получает свежие previews друзей. HUD показывает ВЫБИРАЕТ БЛОК / ВЫБИРАЕТ МЕСТО / ПОСТАВИЛ БЛОК / ПРОПУСТИЛ / ОТКЛЮЧЁН.

Проверяются finite coordinates/grid/bounds/protected areas/overlaps/лимиты. Касание граней допустимо. Защищены start x0–128 и finish x1024–1152 на всю высоту; строительство y176–272. Online максимум 20 блоков (4×5), training 12. Конкурентные запросы не создают наложение; устаревший preview нужно подтвердить заново.

Глобальная проходимость не гарантируется. Можно закрыть маршрут; RACE завершится по timeout с DNF. Удаление блоков, route solver и новые ловушки не входят в 6.1.5.

## RACE и RESULTS

Фаза и spawn задаются сервером. Клиенты отправляют направление и jump counter, сервер рассчитывает движение/контакты и пересечение тела с finish, сохраняет rank и server time. Клиентские координаты не принимаются. При задержке выше окна prediction возможны коррекции; rollback/lag compensation нет.

Все видят одну таблицу раунда. FINISHED — последовательное место и время от старта; DNF — выход/timeout; ABORTED — незавершённый забег при restart API. Места определяет порядок обнаружения серверной симуляцией, в одном обновлении — seat order. Повторный финиш не создаёт второй результат.

NEXT доступен host после RESULTS. Блоки сохраняются; игроки возвращаются к spawn, buildDone сбрасывается. Finish не начисляет валюту, постоянные очки или награды.

## Комнаты и связь

Capacity 2/3/4, default 4. Старт требует ≥2 и READY у всех подключённых. Code — шесть символов; invite открывает Main Mini App и предлагает подтвердить вход. Один пользователь занимает место только в одной активной комнате. После начала новые участники не входят.

Disconnect снимает READY, сохраняет seat/character и показывает reconnect. Input без обновления 300ms отключает контактное тело, чтобы зависший игрок не блокировал остальных; gravity продолжает работать. После восстановления тот же участник получает full map/phase/results, authoritative position и свежие previews. Refresh не создаёт копию. Новое окно аккаунта отключает старое.

Через 30s отсутствия host передаётся подключённому игроку; при LEAVE — сразу. Если ушли все, комната закрывается. Restart прерывает активную гонку, сохраняя blocks/принятые результаты; host продолжает со следующего раунда.

## Персонажи, аккаунт, будущие системы

Altoha (`altoha`), Aigerim (`aigerim`), Temik (`temik`) и Аяжан (`ayazhan`) доступны всем **в online комнате**, бесплатно. Выбор не меняет account selectedCharacterId, ownership или Doner. Все участники могут выбрать одного героя. Shared catalog валидирует IDs; RoomPlayer хранит выбор между reconnect. Lobby показывает одинаковые карточки 2×2.

Character Select содержит четыре варианта для Local Training даже с прежним locked профилем. Выбор для тренировки живёт в текущем приложении; уже owned персонажи сохраняются прежним защищённым profile API, остальные не вызывают select/unlock. После reload начальный выбор снова берётся из сохранённого профиля. Старые ownership/balances не переписываются.

Оригинальные временные герои различаются цветом зимней одежды. У Аяжан тёмно-сиреневое пальто, холодный голубой шарф и полоска/помпон шапки. Это условный прототип, не внешность реального человека. `PlayerVisual` позволяет заменить sheets/frames/body alignment без смены карты. У всех четыре кадра idle/run/air и одинаковая физика. Способностей нет; способность Аяжан — TBD. Финальные sprites и abilities будут отдельным этапом.

Doner, Golden Doner, legacy progress и unlocked characters сохраняются. Магазина/rewards/постоянных очков нет. `PARTY_RULES`/`proposedFinishReward` — неактивные предложения будущих правил, не участвующие в online finish.

Дальнейшие этапы могут добавить ловушки/entitlement/purchases/economy с транзакциями, idempotent settlement, anti-farm и достаточной проверкой движения. Stage 6.2 не начинался.
