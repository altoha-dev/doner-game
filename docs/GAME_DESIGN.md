# DONER GAME — Winter Party Edition

Stage 6.0 / v0.6 Party Reboot Prototype. Концепция Stages 1–5.6 (Solo Campaign и отдельный мир каждого героя) завершена и не определяет новую игру.

## Игровая петля

Будущий матч: 2–4 друга входят в комнату → LOBBY и ready → BUILD (каждый размещает объект) → одновременный RACE → RESULTS → следующий BUILD на той же карте → MATCH_FINISHED и победитель по очкам. Препятствия накапливаются только внутри матча. Следующий матч начинает с базовой геометрии.

Stage 6.0 реализует **одного локального игрока**, BUILD → RACE → RESULTS, до 12 раундов. Кнопки комнат честно сообщают о Stage 6.1. Здесь нет сетевых противников, покупок, очков аккаунта или Doner rewards. Локальная тренировка доступна в обычном браузере и Telegram, включая production-сборку.

## Общая арена

SNOWY CHAOS — рабочее название. Все персонажи используют одну версионированную `SNOWY_CHAOS` из shared: 1152×320 логических пикселей, сетка 16. Есть четыре будущие стартовые позиции, финишная область и несколько уступов. Сплошной нижний пол позволяет обучаться без death/respawn системы. Поверхность визуально ледяная, но текущая физика одинакова для всех материалов.

`ArenaDefinition` разделяет geometry, spawns, finish, placementAreas, protectedAreas. Материалы, декорации и фон определены отдельно в web. Character ID не участвует в выборе карты. Оригинальные временные snow/rock/ice tiles, домики, ёлки, фонари и снеговик не используют скачанные packs.

## BUILD

Один бесплатный BASIC PLATFORM BLOCK 32×16 за раунд. Выбрать → посмотреть preview → коснуться карты или сдвинуть стрелками → подтвердить → начать забег. Отмена убирает ещё не подтверждённый preview. Подтверждение окончательно для текущего раунда.

Карта прокручивается отдельным ползунком; view остаётся в целочисленном масштабе ×2, чтобы блок удобно выбирать пальцем. Стрелки смещают блок на 16 пикселей. Зелёный preview и текст подтверждают допустимость; красный и причина объясняют запрет.

Проверяются конечные числа, сетка, полное попадание в зону строительства, пересечение геометрии и уже поставленных блоков. Касание граней допустимо. Старт x0–128 и финиш x1024–1152 защищены на всю высоту. Верхняя и нижняя границы строительства y176–272. 12 блоков на матч, один на раунд: бесконечное строительство невозможно.

Эти проверки не доказывают проходимость всей трассы: неудачная комбинация может сделать её непроходимой. Для восстановления можно выйти в меню и начать новый матч. Проверку доступности маршрута, удаление/перестановку, лимиты по типам объектов и предельное время раунда нужно решить для online MVP.

## RACE и RESULTS

Сохранились скорость, ускорение, торможение, гравитация, прыжок, coyote time 80ms, buffer 100ms, camera follow, bounds и реальные Arcade-коллизии. Все используют одинаковое тело 10×21. После старта игрок появляется на стартовой площадке. BUILD input отключён; доступны left/right/jump и пауза. Уход приложения в фон/blur ставит локальный забег на паузу и очищает ввод.

Финиш фиксируется пересечением физического тела с finish-областью. RESULTS показывает время активной симуляции, без пауз; это локальная диагностическая метрика, не рекорд и не сетевое место. После следующего раунда старые placements остаются в том же `MatchSnapshot`. Phaser не пересоздаётся между фазами. Новый матч создаёт новую session и пустой список placements; выход в меню/reload также завершает сессию. Сохранения в аккаунт/localStorage нет.

## Персонажи и способности

Стабильные ID: `altoha`, `aigerim`, `temik`. Оригинальные временные спрайты в зимней одежде, разные цвета. `PlayerVisual` описывает текстуру/внешний spritesheet, frame dimensions, origin, body, idle/run/air. Позже достаточно заменить визуальный descriptor и sheets, не менять карту и управление.

Telegram-профиль сохраняет прежние ownership/selected character; доступен выбор уже открытых героев. Покупки персонажей из UI удалены, старый API endpoint сохранён для совместимости. В браузере персонаж выбирается только для локальной тренировки. Способностей нет. `CharacterAbilityDefinition` — расширяемый интерфейс; Temik lift/flight, Aigerim dash и Altoha TBD остаются неутверждёнными идеями.

## Очки и Doner

Doner становится валютой ловушек: дополнительный блок, вентилятор, игровой арбалет, шипы, движущаяся платформа и другие препятствия. Магазина в 6.0 нет. Существующие Doner и Golden Doner не обнуляются и не меняются тренировкой.

| Место | Будущие Doner | Предложение очков |
| --- | ---: | ---: |
| 1 | 0 | 3 |
| 2 | 1 | 2 |
| 3 | 2 | 1 |
| 4+ | 3 | 0 |

Правила сохранены в `PARTY_RULES`, предложение очков можно конфигурировать. DNF, ничьи, disconnect, минимальное число участников, защита от договорного фарма и общий победитель при равных очках требуют решения. `proposedFinishReward` — чистая функция для будущих правил, не начисление. LocalSession не импортирует API и не имеет поля баланса.

Каждый получает бесплатную базовую возможность строить. Doner должны расширять тактику, а не гарантировать победу. Будущие покупки, placement entitlement, лимиты и rewards всегда проверяет сервер. Для тренировки rewards всегда отсутствуют.

## Зимний MVP последующих этапов

2–4 игрока в Telegram; создать комнату и пригласить друга; общая карта; совместный BUILD; одновременный RACE с видимыми соперниками; три типа ловушек; проверенный порядок финиша; очки/Doner; покупка ловушек; несколько раундов и итоговый победитель. Stage 6.1 начинает с работающего соединения друзей и общего состояния, а не со всех систем одновременно.
